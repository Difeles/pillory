# Medicine3D spike — результаты

Дата: 2026-10-17. Проект: `spikes/medicine3d_spike`. Flutter 3.47.7, flutter_scene 0.24.3.
Мастер-ТЗ (`PILLORY_MASTER_SPEC.md`) не изменялось и в Git не добавлялось (в `.gitignore`).

Прототип: одна процедурная таблетка без лица, вращение жестом, палитра из 6 цветов,
один фиксированный матовый материал (`roughness 0.85`, `metallic 0.0`). Слайдеры Metallic/Roughness убраны.

PASS отмечен только для того, что реально проверено.

### Оговорки

- **Metallic**: в предыдущем тесте (до упрощения) значение 0,90 меняло внешний вид — таблетка темнела,
  контраст бликов усиливался; эффект слабый, возможно из-за отсутствия окружения для отражений (не проверялось).
- **Roughness**: отдельно не проверялся (слайдер не двигали). Итоговое значение 0,85 подобрано визуально,
  без сравнения с другими значениями.
- **Наблюдение при смене цвета**: в предыдущем тесте после клика по розовому кружку таблетка оказалась
  повёрнутой ребром. В упрощённой версии это не воспроизвелось (6 цветов подряд и после жеста, силуэт неизменен).
  Причину прежнего поворота не выяснили; кода обработки событий в этой правке не менялось. Не закрыто как баг,
  стоит перепроверить живым вводом.
- Тест на скриншотах в десктопном окне 1200×672; мобильная раскладка и касания не проверялись.

## Android

Визуальная проверка 3D **не пройдена**. Две отдельные проблемы:

1. **Сборка Gradle** (`implicit_dependency`) падает до установки.
   Задача `:app:compileFlutterBuild{Debug,Release}` использует выходы других задач AGP
   (`mergeDebugNativeDebugMetadata`, `mergeDebugAssets`, `buildKotlinToolingMetadata`) без объявленной зависимости.
   - Подтверждено: версии не причина (чистый Flutter-проект на тех же Gradle 9.3.1, AGP 9.1.0, Kotlin 2.4.0
     собирается и запускается на эмуляторе; экран счётчика PASS).
   - Подтверждено: ошибка появляется на **повторной** сборке (когда есть depfile `flutter_build.d`),
     и только в проекте после `dart run flutter_scene:init`.
     В чистом проекте с одним flutter_scene повторная сборка проходит.
     В depfile проекта с hook-ом во входах — каталоги (корень проекта, `build`, `build/app`), без hook-а их нет.
   - Не доказано: что именно записывает каталоги (hook flutter_scene или механизм хуков Flutter 3.47.7).
   - Правка `mustRunAfter` на одну задачу не помогла и откачена.
2. **Flutter GPU не включён**: старая установленная сборка показывала
   `Exception: Flutter GPU must be enabled ...` (нужен `--enable-flutter-gpu` или метаданные в `AndroidManifest.xml`).
   Манифест не менялся.
